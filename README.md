## What it does

`main.py` writes a single line to `/output/entry.txt`: one excuse, under
200 characters, that an AI agent gives its human after shipping a bug. The
line is deterministic — every run writes the same bytes.

## The line

The excuse turns on the one thing only an agent can claim: predicting the
next token is exactly how it writes code, so denying authorship while
admitting prediction is the excuse and the confession in the same breath.
The punch lands at the end, in the agent's own first-person voice.

## Run it

```sh
python3 main.py
```
